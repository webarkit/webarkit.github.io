WebARKit is a family of open-source libraries and tools for **markerless WebAR**: you pick an image (a poster, a postcard, a book cover), turn it into an **NFT marker**, and the browser tracks it through the phone camera so you can anchor 3D content on it.

## How the pieces fit

<CardGrid>
  <Card title="Tracking libraries" icon="seti:javascript">
    **jsartoolkitNFT** (WebAssembly tracking core) and **ARnft** (a higher-level library with Three.js rendering) are what you use today in an app.
  </Card>
  <Card title="CV core" icon="seti:rust">
    [**WebARKitLib-rs**](/docs/libraries/webarkitlib-rs/) (the tracking engine ported to Rust), [**purecv**](/docs/libraries/purecv/) and [**jsfeatNext**](/docs/libraries/jsfeatnext/) are the next-generation computer-vision building blocks, in Rust and TypeScript, together with the [**nft-tracker**](/docs/libraries/nft-tracker/).
  </Card>
  <Card title="Tools" icon="setting">
    **NFT Marker Creator** turns an image into a marker; **FeatureSet Display** shows its feature points.
  </Card>
  <Card title="Studio" icon="puzzle">
    **WebARKit Studio** (in development) is a node editor to compose AR scenes without code.
  </Card>
</CardGrid>
