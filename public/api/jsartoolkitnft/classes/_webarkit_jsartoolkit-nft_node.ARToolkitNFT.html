    addNFTMarkers

    • addNFTMarkers(
          urls: string[],
          callback?: (ids: number[]) => void,
          onError2?: (errorNumber: number) => void,
      ): number[]

      Load the NFT Markers (.fset, .iset and .fset3) in the code. Each entry is the path of the descriptor files without the extension, relative to the working directory. The files are read in place through NODEFS.

      It can be called more than once: ids continue from the markers already loaded (#612). A call that fails reports through onError2 and leaves the markers loaded by earlier calls in place, so it can be retried.

      Parameters

      • urls: string[]

        array of paths of the descriptor files without ext

      • Optionalcallback: (ids: number[]) => void

        the callback to retrieve the ids.

      • OptionalonError2: (errorNumber: number) => void

        the error callback.

      Returns number[]

      an array of ids.

      Implementation of IARToolkitNFT_node.addNFTMarkers

      • Defined in src/ARToolkitNFT_node.ts:543

    configure

    • configure(patch: NFTRuntimeSettingsPatch): void

      Changes several runtime settings at once (#720). The patch is deep-merged into getRuntimeSettings (ar2 field by field) and applied in one native call, which validates everything first and changes nothing on failure.

      logLevel is per controller: the level lives in the WASM module's globals, and each init() creates its own module.

      Parameters

      • patch: NFTRuntimeSettingsPatch

        any subset of the settings.

      Returns void

      Throws

      on an unknown key (including the deprecated square-marker keys threshold, thresholdMode, imageProcMode, debugMode), a value of the wrong type, or a non-integer for an integer field (logLevel, ar2.searchFeatureNum, ar2.templateSize1/2, ar2.searchSize); nothing is changed.

      Throws

      when the values are out of range; nothing is changed.

      Implementation of IARToolkitNFT_node.configure

    • tryAddNFTMarkers(urls: string[]): number[]
      Internal

      The throwing core of addNFTMarkers. Synchronous like it (#685, D9): Node reads the files in place, so there is nothing to await. Shared with the tracker facade (#720 D10); kept out of the public docs. Used by ARControllerNFT_node and nodeTargetLoader, which need the NFTLoadError.

      Returns number[]

      the real marker ids.

      Throws
