    addNFTMarkers

    • addNFTMarkers(
          urls: (string | string[])[],
          callback?: (ids: number[]) => void,
          onError?: (code: number) => void,
          opts?: NFTLoadOptions,
      ): Promise<number[]>

      Loads NFT markers and registers them as one batch.

      Each entry is either a URL without extension (.zft is probed first, then .fset, .iset and .fset3), a URL ending in .zft, or an explicit list of file URLs for one marker.

      All or nothing: if any marker fails, none of this call's markers is registered and its files are removed. Markers loaded by earlier calls stay.

      • Promise style (no callbacks): resolves to the marker ids, or rejects with an NFTLoadError, or with signal.reason (AbortError, TimeoutError) when opts.signal aborts.
      • Callback style (callback and/or onError): never rejects for a load failure. onError(code) is called once, with the HTTP status or -1 (or console.error when there is no onError), and the Promise resolves to [].

      Errors from different bundles are different classes, so test err.name === "NFTLoadError" and err.kind rather than instanceof.

      Parameters

      • urls: (string | string[])[]

        the markers to load, one entry per marker.

      • Optionalcallback: (ids: number[]) => void

        deprecated: receives the ids on success.

      • OptionalonError: (code: number) => void

        deprecated: receives the error code on failure.

      • Optionalopts: NFTLoadOptions

        signal cancels the downloads; probeZFT (default true) probes for a .zft before the three files.

      Returns Promise<number[]>

      the ids the native core assigned, in the order of urls.

      Inherited from ARToolkitNFTBase.addNFTMarkers

    configure

    • configure(patch: NFTRuntimeSettingsPatch): void

      Changes several runtime settings at once (#720). The patch is deep-merged into getRuntimeSettings (ar2 field by field) and applied in one native call, which validates everything first and changes nothing on failure.

      logLevel is per controller: the level lives in the WASM module's globals, and each init() creates its own module.

      Parameters

      • patch: NFTRuntimeSettingsPatch

        any subset of the settings.

      Returns void

      Throws

      on an unknown key (including the deprecated square-marker keys threshold, thresholdMode, imageProcMode, debugMode), a value of the wrong type, or a non-integer for an integer field (logLevel, ar2.searchFeatureNum, ar2.templateSize1/2, ar2.searchSize); nothing is changed.

      Throws

      when the values are out of range; nothing is changed.
