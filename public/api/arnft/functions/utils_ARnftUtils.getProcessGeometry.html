    Function getProcessGeometry

    • getProcessGeometry(
          vw: number,
          vh: number,
          rotatePortrait?: boolean,
          floor?: boolean,
      ): ProcessGeometry

      Compute the geometry used to fit a video of size vw x vh onto the (always landscape) process canvas. When rotatePortrait is true and the video is portrait (vh > vw), the long/short sides are swapped before applying the existing formula so the video can be drawn rotated 90 degrees instead of being letterboxed. With rotatePortrait false/omitted, or for a landscape video, this is identical to the original (unrotated) formula. See https://github.com/webarkit/ARnft/issues/344

      Parameters

      • vw: number

        the video width

      • vh: number

        the video height

      • rotatePortrait: boolean = false

        opt-in flag, see VideoSettingData.rotatePortrait

      • floor: boolean = false

        whether to floor the computed values (CameraViewRenderer always did; getWindowSize historically did not, kept as-is to avoid changing the existing numeric output for callers that don't opt into rotatePortrait)

      Returns ProcessGeometry

      the process canvas geometry
