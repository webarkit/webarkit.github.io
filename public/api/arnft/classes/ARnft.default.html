    StaticinitWithConfig

    • initWithConfig(params: INameInitConfig | IEntityInitConfig): Promise<default>

      Initializes the ARnft instance with the provided configuration. This method can accept either marker URLs and names or an array of entities. It sets up the necessary resources, including the HTML container, stats, camera renderer, and NFT workers. Used internally by the initWithEntities method.

      Parameters

      • params: INameInitConfig | IEntityInitConfig

        The configuration parameters for initialization.

        • INameInitConfig

          INameInitConfig extends IInitConfig and it is used by the initWithConfig method.

          • OptionalautoUpdate?: boolean

            false if you want to maintain it yourself

          • configUrl: string

            the url of the config.json file.

          • height: number

            the height in pixels of the video camera.

          • markerUrls: string[][]

            the Array of url of the markers (without the extension)

          • names: string[][]

            the names of the markers

          • Optionalstats?: boolean

            true if you want the stats.

          • width: number

            the width in pixels of the video camera.

        • IEntityInitConfig

          IEntityInitConfig used by the initWithEntities method

          • OptionalautoUpdate?: boolean

            false if you want to maintain it yourself

          • configUrl: string

            the url of the config.json file.

          • entities: IEntity[]

            the Array of Entity.

          • height: number

            the height in pixels of the video camera.

          • Optionalstats?: boolean

            true if you want the stats.

          • width: number

            the width in pixels of the video camera.

      Returns Promise<default>

      A promise that resolves to the ARnft object.

      Throws

      Will throw an error if neither markerUrls nor entities are provided.
